Gigi Mail

A single-user personal mail assistant. Not a public product.

What it is. A private script running on its owner's own computer. It reads one Gmail account (coolestmcplayer@gmail.com) and one Foxmail account, sorts incoming mail, and writes one short daily summary for that same owner.

What it does with Google data

  • Reads message metadata and content to classify mail (job applications, marketing, receipts).
  • Applies labels and moves messages out of the inbox according to the owner's own rules.
  • Manages the account's own mail filters, and sends reminder mail to the same account.
  • Optionally reads Calendar / Drive / Contacts / Docs / Sheets to build the same daily summary.

What it never does

  • No data leaves the owner's computer except calls to Google's own APIs.
  • Nothing is sold, shared, published or passed to any third party.
  • No other person's account is accessed. There are no other users.
  • No message is ever deleted; changes are limited to labels and inbox placement.
